# facility-demo-superstory

공공시설물 통합관리 솔루션 시연용 프로토타입의 테스트 주소입니다.

- 주소: https://facility-demo-superstory.vercel.app
- 배포: Vercel (`byungmochuns-projects` 팀)
- 용도: 내부 검토·시연, 브이월드 인증키 서비스 URL 등록

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 안내 페이지 (본 화면이 들어가기 전까지 사용) |
| `robots.txt` | 검색엔진 수집 차단 |
| `vercel.json` | 모든 페이지에 `noindex` 헤더 추가 |

## 주의

- 넥서스·실제 지자체의 이름과 로고, 실제 개인정보는 올리지 않습니다.
- 브이월드 인증키는 코드에 직접 넣지 않고 Vercel 환경변수로 관리합니다.
